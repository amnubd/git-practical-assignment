# Git Configuration

Record the output of the following commands after verifying your own Git configuration. Keep the name and email consistent with the identity you want on commits. Do not record tokens, passwords, or other credentials.

```text
Command: git config --global user.name
Output: <record your configured name here>

Command: git config --global user.email
Output: <record your configured email here>

Command: git config --global init.defaultBranch
Output: <record the configured default branch, expected: main>
```

If the default branch is not `main`, configure it with `git config --global init.defaultBranch main`. These values are intentionally left for the repository owner to verify; no identity is assumed by this starter.
